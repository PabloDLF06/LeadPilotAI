# Código de conducta

Esperamos una participación respetuosa, inclusiva y profesional. No se toleran
acoso, discriminación, amenazas, ataques personales ni la publicación de
secretos o datos personales.

Las personas mantenedoras pueden editar, rechazar o retirar contribuciones que
incumplan estas normas. Los incidentes deben comunicarse de forma privada al
mantenedor del repositorio.
