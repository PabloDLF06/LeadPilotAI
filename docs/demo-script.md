# Guion demo (90–150 segundos)

1. **0–15 s:** abre la landing y explica que LeadPilot evita perder consultas
   por responder tarde.
2. **15–40 s:** abre `/f/[publicId]` y envía una solicitud de una clínica dental
   con urgencia y presupuesto.
3. **40–70 s:** entra al dashboard, abre el lead y enseña score, prioridad,
   resumen, siguiente acción y respuesta sugerida.
4. **70–95 s:** enseña Analítica con el rango de 30 días y la etiqueta
   `DEMO_MODE`; comenta que las métricas vienen de la organización actual.
5. **95–120 s:** usa “Crear lead demo” si necesitas repetir el flujo y muestra
   la alerta interna y el log `skipped` cuando n8n está desactivado.
6. **120–150 s:** abre Configuración para enseñar que n8n es opcional y que el
   email puede simularse sin Resend.

No presentes acciones simuladas como envíos reales ni afirmes que Telegram,
Resend o n8n están activos si no se han configurado sus credenciales.
